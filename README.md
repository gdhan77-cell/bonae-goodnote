# 보내굿노트 (Bonae GoodNote)

메모를 보내기만 하면 AI가 폴더를 골라 정리하고, 날짜·시간을 읽어 일정까지 잡아 주는 메모 앱입니다.
굿노트(GoodNotes) 느낌의 서재와 속지·손필기 노트를 함께 담았습니다.

**바로 쓰기 → https://gdhan77-cell.github.io/bonae-goodnote/**

## 무엇을 할 수 있나요

- **보내메모** — 카톡처럼 메모를 보내면 오른쪽 말풍선으로 쌓이고, `✨ AI 정리 · 📁 폴더` 배지가 붙습니다.
  사진 첨부, 브라우저 음성 입력도 됩니다.
- **자동 일정** — "내일 3시", "토요일 오후 7시", "11월 24일", "모레 오전 10시" 같은 표현을 읽어
  왼쪽 알림 봇 카드로 일정을 잡아 주고 `.ics` 파일로 내보냅니다. (30분 전 알림 포함)
- **내 서재** — 폴더별 노트북 카드(색상·메모 수·최근 내용). 폴더를 열면 메모 목록과 노트 편집기가 나옵니다.
- **굿노트식 노트** — 속지 4종(백지·줄노트·모눈·원고지), 텍스트 + 손필기 캔버스(검정·파랑·빨강 펜, 형광펜,
  지우개, 전체 지우기, 굵기, 되돌리기), 인쇄/PDF 저장, `.md`·`.txt` 내보내기.
- **일정 모음** — 날짜가 잡힌 메모만 D-day 순으로 보고 완료 체크, `.ics` 전체 내보내기.
- **삼성 노트로 공유** — `navigator.share`로 안드로이드 공유 시트를 열어 Samsung Notes에 저장.
  PC 등 공유 시트가 없는 곳에서는 클립보드 복사 + 안내로 대체합니다.

## AI 분류 엔진

- **기본(키 없음)**: 한국어 키워드·정규식 분류기 + 한국어 날짜/시간 파서가 내장되어 바로 동작합니다.
- **Claude API(선택)**: 설정에서 Anthropic API 키를 넣으면 문맥 기반으로 폴더·제목·일정을 함께 정리합니다.
  키는 브라우저 `localStorage`에만 저장되며, 연결에 실패하면 내장 분류기로 안전하게 되돌아갑니다.
  (`anthropic-dangerous-direct-browser-access: true`로 브라우저에서 직접 호출)

## 저장과 개인정보

- 모든 메모·폴더·손필기는 이 브라우저의 `localStorage`에만 저장됩니다. 서버로 보내지 않습니다.
- 외부 CDN을 쓰지 않는 **단일 HTML 파일**입니다. `index.html` 하나만 있어도 동작합니다.
- 휴대폰에서 Chrome `⋮ → 홈 화면에 추가`로 앱처럼 열 수 있습니다.

## 파일

- `index.html` — 앱 전체(HTML + CSS + JS, 약 110KB)

### 사용법

⚙ 설정 → **AI 분류 엔진**에서 [무료 AI 자동 전환]을 고르고, 아래 키 풀에 Gemini·Groq·OpenRouter 키를 추가합니다.

## 무료 AI 자동 전환 (2026-11-25 추가)

- **Gemini · Groq · OpenRouter 무료 키**를 여러 개 넣어 두면 순서대로 호출하고, 한도(HTTP 429)·키 오류·서버 오류가 나면 **다음 무료 키로 자동 전환**합니다.
- 키 묶음은 브라우저 `localStorage`의 **`han_free_ai_pool_v1`** 한 곳에 저장되어, 같은 주소(gdhan77-cell.github.io)의 다른 앱과 `free-ai-hub`가 함께 씁니다.
- 옵션 **“무료 AI가 모두 한도 초과일 때만 내 클로드 키로 자동 보완”**(기본 켜짐)을 끄면 100% 무료 AI만 순환합니다.
- 어느 AI가 답했는지 메시지·보고서·상태 표시에 작게 나옵니다.
- 클로드 기본 모델을 **`claude-sonnet-5-5`** 로 올렸습니다. `claude-sonnet-4-5`는 2026-11-30 지원 종료이며, 모델을 찾지 못하면 `claude-sonnet-4-6` → `claude-sonnet-4-5` 순으로 자동 재시도합니다. (Sonnet 5.5는 `temperature`를 받지 않으므로 호출에서 뺐습니다.)
